## About

I've been writing code for five years. I started with C, then C++ and Python: low level taught me what happens under the hood, Python gave me speed.

Linux is my main system and I build it around myself end to end: from my own dynamic island on the panel to a wallpaper that reacts to the music that's playing.

Lately I use AI heavily in development, and the road from idea to working version got much shorter.

My main project right now is Horizon Hammer, a Minecraft mod core in Rust. Alongside it I'm developing linux-island and Mewmori, a local desktop assistant.

## Projects

### [Horizon Hammer](https://hammer.veyron.online)
My mod core for Minecraft: Java Edition, written in Rust. Behaviour is checked against vanilla by 281 differential harnesses, and it installs through the Horizon launcher. Source: [horizon-hammer-core](https://github.com/artemspt/horizon-hammer-core).

### [Mewmori](https://github.com/artemspt/mewmori-linux)
A pixel cat on the desktop: walks over windows, comments on what's going on, listens to your voice and naps on the panel. Runs locally on ollama.

### [Vynkor](https://github.com/vynkor-core/vynkor)
A personal cloud in a single Rust daemon. Plugins in any language run as isolated processes, and your phone joins as a device.

### [Prism Launcher Horizon](https://github.com/artemspt/PrismLauncher-Horizon)
